# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Report it privately with GitHub's private vulnerability reporting. Use the
"Report a vulnerability" button in this repository's security section, or go directly to
https://github.com/konni-arcadia/moontide/security/advisories/new.

Do not open a public issue or pull request first.

Please include:

- what happens
- the steps to reproduce it
- the impact you see
- the Moontide version (`npx -y moontide-mcp --version`)
- your operating system
- a fix, if you have one

## What happens next

The conversation stays in the private advisory. A fix ships in a patch release. If you wish, you
are credited in the advisory and in the changelog.

This is a one-person project. Replies come as soon as possible, with no promised delay.
