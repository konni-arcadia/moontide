# Vision

A person talks to Claude ("start something dreamy in D minor", "darker", "add a bass").
Claude writes Strudel code, and a browser page plays it immediately. Every request becomes
a code change that lands on the next cycle, with no audio cut.

The code is always visible, so the person can watch it play and edit it by hand.

The name: the moon guides the tide. Claude guides the music, and Strudel is the JavaScript
port of TidalCycles.
